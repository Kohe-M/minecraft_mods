# zoom

クライアントのみで動く。サーバー側の mod は不要。設定ファイルはない。

- C キー（`key.zoom.zoom`）を押している間だけズームする。押した直後は 4 倍
- ズーム中のホイールで倍率を 1 段 1.25 倍ずつ変える（1.5〜50 倍）。離すと 4 倍に戻る
  - ズーム中のホイールはホットバーに回さない
- 倍率は 1 tick ごとに目標との比を半分ずつ詰める（対数で補間する）。描画はフレームの間も補間する
- 視点の回転は倍率で割り、画面の上での動きをズームしないときの感度にそろえる
- 手（`calculateHudFov`）とパノラマはズームしない
- 画面を開いている間と、jori で無効の間はズームせず、ホイールはホットバーに回る

## 仕組み

- `Camera.calculateFov` の結果を、画面の中心の見かけの大きさがちょうど倍率になる FOV（`2 atan(tan(fov / 2) / 倍率)`）に変える
- 視点は `MouseHandler.turnPlayer` の前に、たまったマウスの移動量を倍率で割る
- ホイールは `MouseHandler.onScroll` の `ScrollWheelHandler.onMouseScroll` を包み、ズーム中は (0, 0) を返す

## ゲームテスト

- 入ってすぐの最初のカーソル移動は捨てられるので、確かめる前に一度動かしておく
- 倍率は目標に追いつくまで待ってから確かめる
