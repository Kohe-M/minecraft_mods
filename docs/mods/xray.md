# xray

クライアントのみで動く。サーバー側の mod は不要。

- X キー（`key.xray.toggle`）の単押しで鉱石の透視をオン/オフ。オンの間は選んだ鉱石以外のブロックを描かず、鉱石を最大の明るさで描く
- 0.4 秒（8 tick）押し続けるとホイールを開く（短いと単押しのつもりでも開くので、0.25 秒から伸ばした）。中央が全鉱石、外周が鉱石ごと（真上から時計回りにダイヤモンド・エメラルド・金・鉄・銅・石炭・レッドストーン・ラピスラズリ・ネザークォーツ・古代の残骸）
  - マウスの方向で選び、キーを離すか左クリックで確定してオンにする。中心から 20 以内は全鉱石
  - 確定した後にキーを離しても切り替えない
  - 選んだ名前はホイールの上に出す（下はホットバーや体力と重なるので）
- 切り替えと選んだ鉱石はアクションバーに出す
- 設定: `config/xray.txt` に `mode=<鉱石>`（`all`・`diamond` など）。オン/オフは保存せず、起動したときはオフ
- 鉱石の判定は、鉱石ごとの `c:` タグ（`ConventionalBlockTags`）か、バニラの鉱石ブロック。バニラのサーバーは `c:ores` を送ってこないので、バニラの鉱石は直接持つ
- 普通のチェスト（`Blocks.CHEST`）は、どの鉱石を選んでいても見せる。地下の宝箱を探せるように。トラップチェスト・エンダーチェスト・銅のチェストは含めない
- jori で無効の間は透視せず、キーも効かない。戻すと透視し直す

## 仕組み

- チャンク構築が読むワールドのコピーで、隠すブロックを空気として返す。描画器によらず、面のカリングや洞窟カリングも自然に外れる
  - バニラは `RenderSectionRegion.getBlockState`、Sodium は `LevelSlice.getBlockState(III)`（`@Pseudo`）
  - 地中の鉱石は光が届かず真っ暗なので、オンの間はチャンク構築が読む明るさを常に 15 にする
- チェストはチャンクのメッシュではなくブロックエンティティとして描かれる。チャンク構築が空気にしなければ描く一覧に入るので、見せるのは鉱石と同じ判定でよい。描くときは `BlockEntityRenderDispatcher.tryExtractRenderState` を通る（Sodium も同じ）ので、そこで 2 つ変える
  - 明るさは本物のワールドから読まれ、地中では真っ暗になるので、最大にする（`LightCoordsUtil.FULL_BRIGHT`）
  - ふつうは 64 ブロックより遠いブロックエンティティを描かない。鉱石と同じく描画距離いっぱいまで見えるように、`shouldRender` を通す
- 切り替えたら全チャンクを描き直す（`Minecraft.levelExtractor.allChanged()`、F3+A と同じ）。Sodium もこれで作り直す
- オンの状態と鉱石はチャンク構築のスレッドから読まれるので `volatile`

## ゲームテスト

- ホイールは、外周の半径（54）だけずらした位置にカーソルを置いて選ぶ
- オフ・全鉱石・ダイヤモンド・クリックでの確定・jori で無効の間を、スクリーンショットで確かめる
- チェストは、石に埋めたものを見て、画面の中央の半分以上が明るい木の色かを確かめる（光を最大にしないと黒に近く、オフでは石の灰色）。十字の照準が重ならないよう HUD を隠して撮る
  - 72 ブロック先にもう 1 つ置き、`tryExtractRenderState` が返す明るさと、オフでは描かない（null）ことを確かめる。テストの描画距離は 5 チャンク
